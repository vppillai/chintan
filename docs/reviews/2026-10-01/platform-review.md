# Chintan platform review, 1 October 2026 — the debt ledger after rounds 6–8

Four lenses — frontend, backend, platform, docs-and-process — each given the same brief (`lenses/review-brief.md`) and no sight of the others' work, reviewed `main` after the sixty merges of 24 September–1 October: `53bf8a23` (#203) for the frontend, backend and docs lenses, `c636993b` (#207) for the platform lens, whose checkout fast-forwarded as it opened. Main is now `bcd32e86` (#204, Devices & shortcuts folded on You — frontend only; it touches no file or line cited below). Each lens tagged every finding **measured** (a number from a build, a test run, the Actions API, AWS or a script), **traced** (read in code or config) or **reproduced** (run on an orb mirror), and each ended with a "checked and clean" list, so an absence below is a checked absence, not an unlooked-at one. The four reports are committed beside this file under `lenses/`; they are the evidence, this document is the ruling. Nothing in the checkout was edited, no AWS write was made, no comment was posted.

Already in flight and not re-recommended: **BE-1** (Tidy accepts an answer that drops open items; the design doc says the guards refuse it) and **BE-2** (a move does not stamp the target note, so an editor save during the move loses the paragraph in both notes) are PR #208. Known and out of scope per the brief: the checklist depth choice, DB6-9, the recorded owner phone checks, the un-recorded routing replay set, the 320 px capture e2e flake.

## 1. The question and the verdict

The owner asked: *"we need to be sure that we are not adding tech debt or making the platform bad as we go."* Is the platform getting worse as features land?

**Verdict.** No on every axis the lenses could measure, and yes on three they could only count. Measured: every gate is at zero (`go vet`, `staticcheck`, `deadcode -test`, eslint, knip, `check-tokens`, `bun audit`); 1,405 unit tests run in 12 s and 382 e2e in 5.5 min with zero retries over the last twelve main runs; `go test -race -count=3` is clean in 31 s; coverage is 88.5 % pipeline, 85.7 % service, 82.1 % handler, 99.6 % cleanup, 100 % routing; the deployed stacks, bootstrap role and seven alarms match the repository byte for byte; September cost $0.48, of which the workload is about $0.26 a month and provider spend about $1 a month — nothing grew with the sixty merges; and no S3 lifecycle rule can expire a note version before 90 days. Counted: the main chunk grew 35 kB in one round (+7.1 %, 494 → 529 kB raw, 154 → 165 kB gzip) because the push-to-talk gesture layer is now statically in the shell, and three rounds have hand-recorded that number with no CI guard; the stage functions grew (`transcribe` 112 → 174 lines, `moveInto` 84 → 122, `SplitOutput` 93 → 138, `route` 175 → 191) with no size gate; the routing rescue set is 14 deterministic rules and 8 numeric bounds across 3 packages, none retired, four outside any replay, and their "name" bounds disagree (≤ 5, ≤ 8, ≥ 2 words); 65 metrics are emitted and 3 alarmed, so an hour of provider outage ends every capture as "failed" and pages nobody; seven word-splitting rules coexist after R7-2 unified two and a new one landed six PRs later without it; the backlog has 554 rows, 60 ids on more than one row, 11 unmarked near-duplicates and at least 21 of its 62 non-done rows finished and still reading open, with fifty owner decisions in nine places; and CI spent 3,488 job-minutes in five days, about 715 of them re-testing trees already tested, with an uncached 400 MB browser download as the entire wall-clock tail (p95 13 min, worst 28.6 min). The two real defects the round found — an offline edit that is never read back (FE-1) and a move that does not take the stamp S1 introduced for exactly this race (BE-2) — are both at the seam between a new feature and an invariant the codebase already enforces elsewhere, which is the signature of fast rounds, not of rot. The honest summary: the platform is not getting worse where it is measured; it is getting heavier and less legible where nothing measures it — size, rule count, write-only metrics, and the record of what is open — and the single largest debt is governance rather than code: `main` is unprotected, and the production approval the README calls human is a script that approves in 14 seconds.
