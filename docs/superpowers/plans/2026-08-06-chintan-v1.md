# Chintan v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a personal PWA that records voice brain dumps, routes them to notes via vague description, cleans STT with a system setting, and stores navigable raw+cleaned artifacts on serverless AWS — clone-deployable like passbook.

**Architecture:** GitHub Pages PWA → API Gateway + Cognito JWT → Go Lambda (arm64) → DynamoDB index + private S3 content. Per-instance CloudFormation stacks from `config/instances/*.yaml`; shared bootstrap for OIDC deploy role and artifact bucket. Product-first vertical slice; security baseline from day one.

**Tech Stack:** Go 1.22+ Lambda (`provided.al2023`), DynamoDB, S3, Cognito, API Gateway HTTP API, SSM Parameter Store, GitHub Actions OIDC, static ES-module frontend (no bundler), Groq Whisper (STT) + OpenAI-compatible LLM (cleanup) behind interfaces.

**Spec:** `docs/superpowers/specs/2026-08-06-chintan-design.md`

## Global Constraints

- Resource prefix: `chintan-*` only; tags `Project=chintan`, `Instance=<name>`, `Application=Chintan`
- S3 content keys: `tenants/<userId>/notes|captures/...` (never flatten without userId)
- No STT/LLM secrets in repo or frontend; SSM `SecureString` only
- No transcript/audio body content in logs
- Destructive scripts default to dry-run; require `--apply` or `--yes` to mutate
- CORS origin = `https://<owner>.github.io` (Pages); JWT required on all `/v1/*` except health
- Cleanup modes: exactly `faithful` | `polished`; retention default indefinite (`days: 0` means keep forever)
- Module path: `github.com/vppillai/chintan/backend`
- Passbook patterns adapted: bootstrap + `chintan-<instance>-prod` stacks, OIDC role `chintan-github-actions`, environment `production`

**Interfaces:**

  - `func Rank(query string, notes []model.NoteIndex, limit int) []Candidate`

```go
package model

type CleanupMode string
const (
	CleanupFaithful CleanupMode = "faithful"
	CleanupPolished CleanupMode = "polished"
)

type Settings struct {
	CleanupMode   CleanupMode `json:"cleanup_mode"`
	RetentionDays int         `json:"retention_days"` // 0 = indefinite
}

type NoteIndex struct {
	ID        string   `json:"id"`
	Title     string   `json:"title"`
	Aliases   []string `json:"aliases"`
	Snippet   string   `json:"snippet,omitempty"` // first ~500 chars of note for light match
	UpdatedAt string   `json:"updated_at"`
	S3MarkdownKey string `json:"s3_markdown_key"`
	S3MetaKey     string `json:"s3_meta_key"`
}

type CaptureStatus string
const (
	StatusUploaded    CaptureStatus = "uploaded"
	StatusTranscribed CaptureStatus = "transcribed"
	StatusCleaned     CaptureStatus = "cleaned"
	StatusAppended    CaptureStatus = "appended"
	StatusFailed      CaptureStatus = "failed"
)

type CaptureIndex struct {
	ID        string        `json:"id"`
	NoteID    string        `json:"note_id"`
	UserID    string        `json:"user_id"`
	Status    CaptureStatus `json:"status"`
	Mode      CleanupMode   `json:"cleanup_mode"`
	AudioKey  string        `json:"audio_key"`
	RawKey    string        `json:"raw_key"`
	CleanKey  string        `json:"clean_key"`
	Error     string        `json:"error,omitempty"`
	CreatedAt string        `json:"created_at"`
}
```
